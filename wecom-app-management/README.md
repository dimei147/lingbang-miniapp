# 企微应用管理

[在线查看](https://dimei147.github.io/lingbang-miniapp/wecom-app-management/) · [返回原型目录](https://dimei147.github.io/lingbang-miniapp/)

以应用为配置主体，统一维护应用基础信息、企业微信接入及建群规则。

- 列表支持筛选、新增应用。
- “编辑基础信息”和“配置建群规则”分别打开独立弹窗，分别保存，不提供弹窗内切换入口。
- 弹窗限制高度，表单区域可滚动，标题和底部操作按钮固定。
- 新增应用先保存基础信息，再从列表配置建群规则。

页面仅使用示例配置，修改保存在当前浏览器本地，不调用生产接口。请勿输入真实密钥或机器人地址。

`index.html` 与 `企微应用管理-logo.png` 需放在同一目录。
